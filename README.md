# YouTube Summary Studio

A full-stack AI learning platform for YouTube lecture study, summarization, and tutoring.

## Architecture

The application has one backend API, with a dedicated RAG service used by that backend:

1. Frontend
   - React + Vite + TypeScript
   - Responsible for the dashboard, import flow, workspace, and tutor UI
   - Runs on: http://localhost:5173

2. Node.js backend API
   - Express + MongoDB
   - The only application backend; responsible for API routing, lecture persistence, and orchestration
   - Runs on: http://localhost:4000

3. RAG service
   - Python FastAPI service called by the Node.js backend
   - Responsible for transcript indexing, retrieval grounding, and LangGraph summaries
   - Runs on: http://localhost:8001

## Project Structure

- `frontend/` — React application
- `backend-node/` — Node.js server and MongoDB models
- `rag-service/` — Python RAG and summary service used by the Node.js backend

## Prerequisites

Before running the project, make sure you have:

- Node.js 18+
- npm
- UV (Astral)
- MongoDB running locally

You can install and run MongoDB locally with:

- MongoDB Community Edition, or
- Docker:

```bash
docker run -d --name mongo-youtube-summary -p 27017:27017 mongo:latest
```

## Environment Variables

Create a `.env` file in the project root with the following values:

```env
PORT=4000
MONGO_URI=mongodb://127.0.0.1:27017/youtube-summary-studio
RAG_SERVICE_URL=http://localhost:8001
GEMINI_API_KEY=
GEMINI_MODEL=gemini-2.0-flash
LANGSMITH_API_KEY=
LANGSMITH_TRACING=true
LANGSMITH_PROJECT=youtube-summary-studio
EMBEDDING_PROVIDER=google
EMBEDDING_MODEL=text-embedding-004
APP_SECRET=change-me
APP_ENV=development
```

## Run the Project

### Start MongoDB

Make sure MongoDB is running locally.

### Start the RAG service

```bash
cd rag-service
uv run uvicorn main:app --host 0.0.0.0 --port 8001
```

### Start the Node backend

```bash
cd backend-node
npm start
```

The Node API will run at:

- http://localhost:4000/api/health

### Start the React frontend

```bash
cd frontend
npm run dev
```

The app will run at:

- http://localhost:5173

## API Flow

The frontend calls the Node backend at `http://localhost:4000/api`.

The Node.js backend does the following:

- validates the YouTube URL
- stores lecture metadata in MongoDB
- calls the RAG service for transcript indexing, retrieval grounding, and summary generation
- returns the lecture summary and tutor payload to the React app

Lecture summaries are generated by a LangGraph agent using LangChain's Gemini chat model. Set `GEMINI_API_KEY` to enable model summaries; set `LANGSMITH_API_KEY` to trace graph/model runs in LangSmith. Model invocation start, success, and failure are written to the RAG service log with the agent, provider, model, and request ID.

On the import page, start and end timestamps are optional. Enter both as `mm:ss` or `hh:mm:ss` to summarize only transcript segments overlapping that interval; leave both blank to summarize the whole video.

The RAG service is a companion service, not a second application backend. It exposes endpoints used by Node, such as:

- `GET /health`
- `POST /api/index`
- `POST /api/search`

## Notes

- The app uses a 24-hour cache for repeated lecture summaries and tutor responses.
- The current retrieval layer is a grounded indexing flow and is ready to be upgraded to semantic embeddings and Qdrant later.
- The Mongo store is the persistent layer for lecture metadata and transcript records.

## Common Issues

### MongoDB connection issues

Make sure MongoDB is running and that `MONGO_URI` matches your local setup.

### RAG service not reachable

Check that the RAG service is running on port 8001 and that `RAG_SERVICE_URL` points to it.

### Frontend cannot reach backend

Make sure the backend is running on port 4000 and that the React config uses the correct API base URL.
